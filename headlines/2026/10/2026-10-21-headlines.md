- [DeepInfer: DeepSeek's Production Inference Framework](https://github.com/deepseek-ai/DeepInfer) — DeepSeek open-sources the orchestration layer behind its production services, integrating FlashMLA, DeepGEMM, DeepEP, and TileLang kernels; supports NVIDIA SM100 and Huawei Ascend 950; Apache 2.0. *(October 20, 2026)*

- [TorchTPU: Running PyTorch Natively on TPUs at Google Scale](https://github.com/google-pytorch/torch_tpu) — Google publishes the long-planned public GitHub repository for TorchTPU, a successor to PyTorch/XLA that uses PyTorch's PrivateUse1 interface for native tensor integration and adds MPMD support; Apache 2.0. *(October 20, 2026)*

- [Voxtral 3](https://mistral.ai/news/voxtral-3/) — Mistral's new speech model family: transcription (50+ languages, speaker diarization), TTS (35+ languages, voice cloning, emotion controls), and a voice agent SDK built on LiveKit with sub-500ms transcription and under-one-second agent turns; API only, licensing unstated. *(October 21, 2026)*
