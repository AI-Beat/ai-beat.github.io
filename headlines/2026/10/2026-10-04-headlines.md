# AI Headlines — 2026-10-04

- [Kolibri: A Sovereign Open-Weight Model](https://aleph-alpha.com/en/blog/kolibri-has-landed-a-sovereign-open-weight-model/) — Aleph Alpha releases Kolibri-1, a 78B MoE model (3.46B active per token, 384 experts, 1M context) trained entirely in Germany and Finland; built-in abstention via the Merlin-Arthur protocol; German-English bilingual focus for regulated European deployments; weights on HuggingFace. *(October 3, 2026)*

- [Index-Translate: 35B MoE for 150 Languages](https://huggingface.co/IndexTeam) — Bilibili's Index LLM Team open-sources a 35B-A3B MoE translation model family covering 150 languages under Apache 2.0; only 3B parameters active per token; includes specialized Echo (speech translation), Homura (syllable-constrained dubbing), and NativeLong (full-document) checkpoints; matches frontier models on FLORES COMET-22. *(September 30, 2026)*

- [Agents don't need memory, they need documentation](https://liao.gg/blog/agents-dont-need-memory) — Post arguing that RAG-based agent memory is fragile because similarity search surfaces wrong context, loses surrounding motivation, and becomes stale; proposes Markdown-based workspace documentation as the alternative, with an open-source reference implementation. *(October 4, 2026)*

- [Pi pod: Run your coding agent in sandboxes on your own server](https://pipod.dev/) — Show HN project for self-hosting a Pi coding agent in isolated sandboxes on your own hardware, avoiding cloud API dependencies. *(October 3-4, 2026)*
