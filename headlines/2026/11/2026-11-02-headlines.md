# AI Headlines — 2026-11-02

- [Proving and Improving the Platonic Representation Hypothesis with JEPAs](https://arxiv.org/abs/2610.39302) — Balestriero and LeCun formally prove that JEPAs trained on any modality learn the same representation up to rotation, and show a 109M text JEPA aligns with vision encoders better than any LLM up to 72B parameters. *(October 29, 2026)*

- [The AI cost of JavaScript frameworks](https://nolanlawson.com/2026/10/28/the-ai-cost-of-javascript-frameworks/) — An empirical study building the same app across ~12 frameworks with Claude Opus 5.5 finds a near 2x cost spread ($2.67 to $4.97/run), with verbosity and scaffolding complexity as likely drivers; raises the question of whether AI-era framework choices should be evidence-based. *(October 28, 2026)*

- [Postgres 19 is late because so many more bugs are being found now](http://rhaas.blogspot.com/2026/10/postgres-19-is-late-and-its-ais-fault.html) — Robert Haas explains that LLMs are surfacing latent bugs in the PostgreSQL codebase faster than committers can fix them, increasing back-patches and delaying the release. *(October 28, 2026)*
