# AI Headlines — 2026-11-06

- [P-JiT: A Decent Text-to-Image Model Trained for ~$21K (Apache 2.0 Weights)](https://www.linum.ai/field-notes/pjit-21k) — Linum releases a 2B pixel-space text-to-image model trained from scratch for $21,038 on 64 H100s, with weights and code under Apache 2.0; architecture skips the VAE entirely, using 32×32 patches and a frozen Qwen3.5-4B text encoder. *(November 4, 2026)*

- [Inkling 2 Small](https://thinkingmachines.ai/news/inkling-2-small/) — Thinking Machines Lab (Philippines) releases a 594B/17B-active MoE model pretrained natively in NVFP4 on 8.4T tokens and post-trained with a single joint RL run of 1,075 steps / 17M rollouts; claims best open-weight scores on several finance benchmarks; Apache 2.0 weights pending external safety review. *(November 5, 2026)*

- [ERNIE 5.5 Flash Base](https://ernie.baidu.com/release/ernie-5-5-flash-base/) — Baidu releases base pre-training checkpoint for a 280B/14B-active MoE model trained on 33.5T tokens; notable for ECHO (a multi-token prediction replacement), a MultiMax output head, and a digit-grouping tokenizer; custom license, not formally open-source. *(November 5, 2026)*

- [Closed AI Models Now Dominate the Price-Performance Frontier](https://village.dev/blog/closed-ai-models-now-dominate-the-price-performance-frontier/) — Village analysis shows open-weight models held the best price-performance at only 3% of budget points by October 31, 2026, down from 41% in June; closed model families from OpenAI and Anthropic reclaimed most of the range. *(October 30, 2026)*
