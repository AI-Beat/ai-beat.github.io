# AI Headlines — 2026-11-18

- [AI Coding Agents Shifted the Bottleneck to Code Review](https://complexdiscovery.com/harvard-researchers-find-ai-coding-agents-shifted-the-bottleneck-to-code-review/) — Harvard working paper covering 718 firms and ~726K workers finds AI coding tools added ~30% more code volume but no measurable rise in throughput; PR-to-merge time rose 49% and change-request rate nearly doubled. *(November 2026)*

- [FrontierHarness Eval v1.1](https://runta.com/blog/introducing-frontierharness-eval-v1-1/) — Runta's benchmark of 22 agent harness configs across 5 models finds 64.5% of agent inference spend goes to failed runs; higher per-run cost within a model does not predict better pass rates. *(November 18, 2026)*

- [MAI Code 2 and MAI Code 2 Flash](https://microsoft.ai/news/introducing-mai-code-2-and-mai-code-2-flash/) — Microsoft announces two coding-specialized models at Ignite claiming ~96% of Claude Opus 5.5 benchmark performance at ~5% of the cost and ~98% of GPT-6.1 Sol at ~40% the cost. *(November 17, 2026)*

- [Cerebras Disaggregated Inference](https://www.cerebras.ai/blog/cerebras-launches-disaggregated-inference) — Cerebras splits LLM inference across GPU-handled prefill and wafer-scale chip decode, reporting 5× throughput/MW in production on GPT-OSS-120B with no loss in generation speed. *(November 18, 2026)*
