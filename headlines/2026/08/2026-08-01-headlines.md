# AI Headlines — 2026-08-01

- [qm: Multiplayer agent harness for work](https://github.com/yc-software/qm) — Y Combinator open-sources qm ("quartermaster"), the internal multi-agent harness they run across accounting, legal, events, and engineering; gives each employee isolated scoped workspaces (memory, files, permissions, sandboxes) while supporting shared rooms and channels, with pluggable support for Pi, OpenCode, Codex, and Claude Code backends. *(July 31, 2026)*

- [WASTE: Run Kimi K3 using 29 GB of RAM at 0.50 tok/s](https://github.com/sqliteai/waste) — SQLiteAI's dependency-free C library runs the 2.78T-parameter Kimi K3 on consumer hardware by keeping the 27GB resident trunk in RAM and streaming activated experts from NVMe with exactly one pread() per expert; experts stored at 3-bit residual vector quantization in 4KB-aligned records, with LFRU caching for the remaining RAM and a 53× KV cache compression via projection absorption. *(August 1, 2026)*

- [Is AI Reasoning Right for the Wrong Reasons?](https://www.quantamagazine.org/is-ai-reasoning-right-for-the-wrong-reasons-20260731/) — Quanta synthesizes recent research on chain-of-thought faithfulness: 30-60% of "thinking steps" have minimal causal impact on outputs, filler tokens (dots) can substitute for actual reasoning text, and replacing correct traces with wrong ones doesn't degrade performance — Kambhampati's "approximate retrieval" hypothesis suggests reasoning tokens are context-loading aids rather than narrations of genuine step-by-step computation. *(July 31, 2026)*

- [Twenty-five years ago it was cryptography, today it's model weights](https://weeraman.com/because-we-can/) — A developer draws a direct parallel between 1990s encryption export controls and today's AI model access restrictions, arguing both approaches bind law-abiding actors while failing against determined adversaries; notes the irony that commercial AI APIs blocked defenders during the Hugging Face agent intrusion investigation while attackers faced no such constraints. *(July 26, 2026)*
