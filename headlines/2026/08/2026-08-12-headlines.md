# AI Headlines — 2026-08-12

- [Stealing Reasoning Traces from Proprietary LLM APIs](https://arxiv.org/abs/2608.09867) — Researchers show OpenAI, Anthropic, and Google were storing encrypted chain-of-thought client-side; shared encryption keys across model families let attackers replay strong-model traces into jailbroken siblings to recover plaintext reasoning; 315K blocks analyzed, 367 PII artifacts and 182 credentials found; all providers patched. *(August 10, 2026)*

- [Mojo 1.0 Is Here](https://www.modular.com/blog/modular-26-5-mojo-1-0-is-here) — Modular ships Mojo 1.0, marking the language's first stability commitment; the compiler and toolchain will be open-sourced in 2026; nearly 200 contributors have touched 200k+ lines of standard library code since it opened in 2024; used in production for Modular's commercial infrastructure. *(August 11, 2026)*

- [NVIDIA Nemotron 3.5 Lightning and NeMo Switchyard](https://blogs.nvidia.com/blog/nemotron-lightning-switchyard-rtx-dgx/) — A 30B MoE model targeting high-volume specialized tasks (code review, security monitoring, tool use) with 4× faster output than comparable models, plus an open-source routing library that directs API requests across a model fleet by quality/latency/cost priority, cutting costs to roughly one-third of using a frontier model alone. *(August 11, 2026)*

- [Compression Is Prediction](https://ngrok.com/blog/compression-is-prediction) — A technical essay tracing the mathematical equivalence between data compression and language modeling: both minimize cross-entropy, both reduce to the problem of accurately predicting the next symbol; uses arithmetic coding to make the connection concrete. *(August 11, 2026)*
