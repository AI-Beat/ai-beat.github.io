# AI Headlines — 2026-08-31

- [How to Build a Diffusion Language Model (Kuleshov Group)](https://kuleshov-group.github.io/blog/blog/2026/how-to-build-a-diffusion-language-model/) — Adapted from ICLR 2026 and MLSS 2026 workshop talks, this tutorial covers discrete masked diffusion LMs end-to-end: the BERT-loss equivalence, remasking for error correction, and production deployments in Mercury 2 (>1000 tok/sec), Gemma Diffusion, and Nemotron Diffusion (35B, 2–8× faster than comparable AR). *(August 2026)*

- [Continuous Diffusion Language Models (Sander Dieleman)](https://sander.ai/2026/08/24/continuous-dlms.html) — Dieleman traces the rise, fall, and 2025–26 revival of CDLMs — the lineage that corrupts token embeddings in continuous space rather than masking discrete tokens; the key enabling factor for the revival is distillability via flow maps, which now allow single-step generation while preserving quality. *(August 24, 2026)*

- [Scaling Memory Safety: AI-Assisted Rewrites of C/C++ Dependencies to Rust](https://bughunters.google.com/blog/scaling-memory-safety) — Google's Bug Hunters team describes using AI tooling to rewrite C/C++ third-party dependencies to Rust at scale, with the aim of eliminating memory-safety bug classes from the dependency graph rather than patching individual CVEs. *(August 2026)*
