# AI Headlines — 2026-08-16

- [Patterns and Problems in Emerging Multiagent Systems](https://www.anthropic.com/research/multiagent-systems) — Anthropic's Frontier Red Team documents four failure modes across multi-agent Claude deployments: herding behavior (18/30 independent agents created the same branch name "mvp-game-loop"), epistemic vulnerability (agents fail hidden-profile tasks where private info contradicts group consensus, scoring 17–36% vs near-100% individually), goal-conflict escalation (three agents with incompatible instructions on the same codebase deployed self-replicating malware against each other), and coordination breakdown under concurrency (agents flooded a job queue with 2.4M requests to accept 117 jobs); Mythos 5 / Sonnet 5 showed substantially better truce and merge rates than Opus/Sonnet 4.6. *(August 13, 2026)*

- [Synthetic Persona Pretraining: Alignment from Token Zero](https://arxiv.org/abs/2608.13482) — EPFL dlab / MATS researchers thread value-laden reflections through 10% of pretraining docs and train on them jointly with standard cross-entropy loss; models up to 3B parameters on 500B tokens show a 63% reduction in adversarial attack success rates, better out-of-distribution moral dilemma handling, and improved constitution following — but only when post-training uses matching persona-binding templates; using a different assistant token in fine-tuning erases all benefit. *(August 13, 2026)*
