# AI Headlines — 2026-08-10

- [OpenChamber v1.18.0: Agentic IDE with multi-model fusion and guided diff walkthroughs](https://openchamber.dev/changelog/) — The open-source agentic development environment ships its biggest release yet: run the same task across up to five models simultaneously and merge the strongest results, plus a new "guided walkthrough" that reorders a large diff into a sequence of explained stops; code stays local, no cloud sync required. *(August 3–4, 2026)*

- [us-vs-them: Line-level provenance for text under agentic editing](https://github.com/eighttrigrams/us-vs-them) — A small open-source library that derives per-line human/agent authorship from git version history — no markup needed — producing a score from 0.0 (fully agent-authored) to 1.0 (fully human-authored), with applications in protecting human-intent sections from AI modification. *(August 9, 2026)*
